# Web design guidelines for Cosmos

Read the [Vercel Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines) if available. Apply the following local review when running offline.

- Check primary actions, navigation, form states, loading feedback and user-facing error recovery.
- Check focus visibility, semantic markup, controls and links, tap targets, readability and text wrapping.
- Check responsive overflow, motion preferences, asset sizing and layout shifts.
- Report each verified problem as file and line when available, symptom, impact and fix. Identify which findings have a browser reproduction.
- Use the dedicated Web Accessibility skill for detailed accessibility review and keep unmeasured conditions open.
