# Impeccable for Cosmos

This entry point is an adaptation. Use the upstream [craft floor](reference/craft-floor.md) and [critique rubric](reference/critique-rubric.md) as reading material. Cosmos provides the rendering and evidence workflow.

1. Identify the surface goal. Choose expressive composition for a landing page or high-density clarity for a tool.
2. Inspect a real render at its shipping sizes. Assess hierarchy, spacing, type, states and brand fit.
3. Describe each visible issue with its location, user effect, severity and one implementable change.
4. Fix the most important issues first and capture again. State any unmeasured dimensions.
