# Taste Skill for Cosmos

This entry point adapts Taste Skill for portable clients. Follow the project identity and existing conventions.

- Start with the actual product and audience. Choose one clear visual system and a purposeful shift in rhythm across the page. See [layout](references/layout-v4.md) and [system](references/system.md).
- Name the product, outcome and next action in the user's language. Edit vague claims using the [copy guide](references/copy.md).
- Inspect the visual result on mobile and desktop. Use [motion](references/motion.md) for a brief entrance, one interaction and a reduced-motion state when appropriate.
- Use provided or cleared assets. Replace upstream asset, build and checker commands with the project's own tools or Cosmos examples and measurements.
