# Installation privée

Claude Desktop sur macOS : Paramètres, Application de bureau, Extensions, Gérer, Paramètres avancés, Installer l’extension, puis sélectionner le fichier MCPB. Pour le catalogue, le dossier de projet est facultatif. Pour auditer, le sélectionner et disposer de Node, Playwright Core et Chromium selon le projet. Une installation Claude Desktop n’a pas été qualifiée dans cet environnement Linux.

Codex et Cursor : décompresser le projet local, puis configurer un seul serveur stdio pointant vers `python3 -B /chemin/vers/skills/get-started/scripts/server.py`. Réutiliser le manifeste existant sur les hôtes qui l’acceptent. Définir `COSMOS_PROJECT_ROOT` seulement pour le projet sélectionné. Voir le guide de démarrage du paquet pour les étapes d’audit.

Essai : « Crée une landing page pour une documentation produit. Démontrer l’aperçu en direct et l’accès aux différentes versions. » Le workflow devrait renvoyer les pages complètes et inviter à en ouvrir les extraits. Une activation spontanée dépend de l’hôte.
